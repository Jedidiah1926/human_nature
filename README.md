# Human Nature — 세계 의회 (World Assembly)

> 지구인 누구나 의원이 되는 온라인 의회 게임. NationStates처럼 전 세계 사람이 접속해 정당을 만들고, 입당·탈당하고, 의제에 표결합니다.
> 화면과 반원형 의석은 [Hemicycle](https://github.com/Jedidiah1926/parliament)의 네온 CRT 스타일과 좌석 배치 방식을 그대로 따릅니다.

## 할 수 있는 것

- **의원 등록** — 아이디·비밀번호 또는 **Discord / Google 로그인**. 의원 이름·국가(국기)·**프로필 사진**. 한 계정 = 의석 하나. 기존 계정에 Discord·Google을 나중에 연결하거나 끊을 수 있음.
- **의원 프로필 · 친구** — 의원마다 공개 프로필(`#/member/ID`). 친구 신청 → 상대가 수락하면 친구.
- **디스코드 ID 공개 범위** — 프로필에 디스코드 ID를 표시하고, 보여줄 대상을 **모든 사람 / 친구 / 같은 당 당원** 중 원하는 만큼 따로 켜고 끔(아무것도 안 켜면 나만 보임). 서버가 보는 사람마다 걸러서 내려보내므로 권한 없는 사람에게는 아예 전달되지 않음. Discord로 로그인해 연결한 ID는 "확인됨 ✓", 직접 입력한 ID는 확인 안 됨으로 표시.
- **반원형 의석** — 모든 의원이 한 의석. 정당을 이념(좌→우) 순으로 부채꼴로 배치하고 무소속은 맨 끝. 좌석에 마우스를 올리면 의원·국가·소속 표시, 내 자리는 금색 고리.
- **정당** — 누구나 창당(이름·약칭·색·이념 −100~100·강령·**로고**·**지도부 명칭**: "대표" 대신 총재·위원장 등). 입당 / 탈당 / 다른 당으로 옮기기. 정당마다 상세 페이지(`#/party/ID`)에서 당원 · 직책 · 공지 · 입당 신청을 관리.
- **당내 직책 · 권한** — 대표가 직책(부대표, 원내대표, 대변인…)을 원하는 이름으로 만들고 권한을 골라 부여합니다.
  | 권한 | 할 수 있는 것 |
  |------|---------------|
  | 정당 정보 수정 | 이름 · 색 · 이념 · 강령 · 커뮤니티 링크 |
  | 공지 작성 | 당 공지 (정당 목록·상세 페이지 상단에 표시) |
  | 입당 승인 | 입당 방식(자유 / 승인제) 변경, 신청 승인 · 거절 |
  | 당원 제명 | 서열이 낮은 당원 제명, 24시간 재입당 금지 |
  | 직책 관리 · 임명 | 자기보다 낮은 직책 생성 · 수정 · 삭제 · 서열 조정, 당원 임명 · 해임 |
  | 당론 지정 | 의제마다 당의 공식 입장(찬성 · 반대 · 기권 · 자유 투표) |
  - 직책 목록 순서가 곧 **서열**. 대표는 모든 직책 위에서 모든 권한을 가집니다. 누구든 **자기보다 낮은 서열**만 다룰 수 있고, **자기가 가진 권한만** 남에게 줄 수 있습니다.
  - **대표 직접 위임** — 대표가 원하는 당원에게 대표 자리를 바로 넘기고, 넘긴 뒤 자기가 맡을 직책을 고를 수 있습니다.
  - **대표는 탈당할 수 없음** — 위임하거나 **정당 해산**(대표만, 정당 이름을 그대로 입력해 확인). 해산하면 당원은 모두 무소속이 되고, 지난 표결 기록에는 정당 이름·색이 남습니다.
- **당 게시판 = 외부 커뮤니티** — 게임 안에 게시판을 두지 않고, 정당마다 Discord 서버 / Reddit / 디시인사이드 갤러리 / 기타 링크를 걸어 둡니다.
- **법안 흐름: 발의 → 추천 → 본회의 상정 → 표결**
  - 누구나 발의(한 사람당 추천 단계·표결 중 합쳐 3개까지). 발의자는 자동으로 첫 추천인.
  - **추천 / 비추천**(다시 누르면 취소). 추천이 `max(SPONSOR_MIN, 재적 × SPONSOR_RATIO)` 이상이고 비추천보다 많으면 **본회의에 상정**되어 발의 때 정한 기간(1시간~7일) 동안 표결. 7일 안에 못 모으면 폐기.
  - 당론은 추천 단계에서도 미리 정할 수 있음.
- **의제 표결** — 찬성·반대·기권. **표 변경 · 철회는 종료 12시간 전까지**(12시간 이하 표결은 기간의 절반 시점까지), 그 뒤에는 아직 투표 안 한 사람의 첫 투표만 가능. 표결 화면의 반원은 표에 따라 칠해지고(테두리는 정당 색) 정당별 표결 표에 당론과 당론 이탈자 수가 함께 나옵니다. 찬성 > 반대면 가결(`QUORUM`으로 최소 투표율 설정 가능). 마감된 의제는 마감 순간의 의석 구성을 기록해 둡니다.
- **실시간** — 누가 입당하거나 투표하면 접속한 모든 사람의 화면이 바로 갱신(Server-Sent Events).
- **한국어 / English** 전환.

## 실행

Node.js 18 이상, 설치할 패키지 없음.

```bash
npm start            # http://localhost:3000
npm test             # API 테스트
```

데모 데이터(가상 의원 300명·정당 5개·의제 1개)로 보고 싶으면:

```bash
REGISTER_PER_HOUR=0 npm start
node tools/seed.js 300            # 다른 터미널에서
```

### 환경 변수

| 이름 | 기본값 | 설명 |
|------|--------|------|
| `PORT` | `3000` | 포트 |
| `DATA_DIR` | `./data` | 저장 위치 (`db.json`) |
| `QUORUM` | `0` | 가결에 필요한 최소 투표율 (0~1, 기권 포함) |
| `REGISTER_PER_HOUR` | `5` | 같은 IP에서 1시간에 가입 가능한 수 (0 = 제한 없음) |
| `SPONSOR_MIN` | `3` | 본회의 상정에 필요한 최소 추천 수 |
| `SPONSOR_RATIO` | `0.05` | 또는 재적 의원의 이 비율 (둘 중 큰 쪽, 재적 의원 수를 넘지 않음) |
| `PUBLIC_URL` | `http://localhost:PORT` | 외부에서 접속하는 주소 — 소셜 로그인 리디렉션 주소에 쓰임 |
| `DISCORD_CLIENT_ID` · `DISCORD_CLIENT_SECRET` | — | 있으면 Discord 로그인 켜짐 |
| `GOOGLE_CLIENT_ID` · `GOOGLE_CLIENT_SECRET` | — | 있으면 Google 로그인 켜짐 |

### Discord / Google 로그인 설정

1. **Discord**: [Discord Developer Portal](https://discord.com/developers/applications) → New Application → OAuth2 → Redirects에 `PUBLIC_URL/auth/discord/callback` 추가 → Client ID · Client Secret을 환경 변수로.
2. **Google**: [Google Cloud Console](https://console.cloud.google.com/apis/credentials) → OAuth 클라이언트 ID(웹 애플리케이션) → 승인된 리디렉션 URI에 `PUBLIC_URL/auth/google/callback` → Client ID · Secret을 환경 변수로.

설정이 없는 로그인 방법은 화면에 버튼이 나오지 않습니다. 프로필 사진·정당 로고는 `DATA_DIR/uploads`에 저장됩니다(브라우저에서 256px로 줄여 올림, 최대 300KB, PNG·JPG·WebP·GIF).

## 전 세계에 공개하려면

모든 사람이 같은 의회를 공유해야 하므로 GitHub Pages 같은 정적 호스팅만으로는 안 되고, 이 서버를 계속 켜 둘 곳이 필요합니다 — Render · Railway · Fly.io · VPS 등에 `npm start`로 올리고 `DATA_DIR`을 영구 디스크로 지정하면 됩니다.

## 구조

| 파일 | 내용 |
|------|------|
| `server.js` | 정적 파일 + JSON API + SSE, `data/db.json`에 저장 |
| `public/index.html` · `style.css` · `app.js` | 화면 (의회 · 정당 · 의제 · 내 의석) |
| `public/hemicycle.js` | 반원형 의석 배치·그리기 (Hemicycle에서 옮겨 옴) |
| `public/fonts/neodgm` | 네오둥근모 (SIL OFL 1.1) |
| `tools/seed.js` | 데모 데이터 |
